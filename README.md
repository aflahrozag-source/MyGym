# Pertemuan-4

My Routine Gym adalah aplikasi web interaktif yang dirancang sebagai pelacak dan pengelola latihan beban harian secara terstruktur. Aplikasi ini dibangun murni menggunakan kombinasi HTML, CSS, dan JavaScript untuk memberikan pengalaman melacak aktivitas gym yang praktis, responsif, dan elegan.

Fitur-fitur utama yang tersedia di dalam aplikasi ini meliputi:

Pilihan Split Workout Harian: Navigasi interaktif untuk memilih jadwal latihan utama (Push Day, Pull Day, dan Leg Day).

Fleksibilitas Target Set & Repetisi: Pengaturan jumlah target set dan repetisi secara dinamis sesuai konsep compound movement.

Sistem Indikator Progres Ganda: Persentase progres yang dihitung secara real-time, baik untuk setiap menu latihan individual maupun total akumulasi progres harian.

Inline Rest Timer: Penghitung waktu istirahat antar-set pada tiap menu latihan yang dapat disetel, dijalankan, dihentikan, dan diulang (start, stop, reset).

Kalender & Jam Realtime: Tampilan tanggal dan jam digital yang berjalan secara real-time, lengkap dengan fitur penanda/catatan khusus pada tanggal yang dipilih.

Pengaturan Rest Day Mingguan: Fitur kustomisasi hari pemulihan (Rest Day) harian beserta rekomendasi aktivitas pemulihan otot yang relevan.

Banner Pengingat Harian: Imbauan jadwal latihan harian yang menyesuaikan secara otomatis berdasarkan hari dan tanggal berjalan.

Profil Pengguna Kustom: Modul untuk mengelola data diri pengguna seperti nama, nomor HP, alamat, serta unggah foto profil.

Pengatur Tema (Dark/Light Mode): Fitur untuk mengubah tampilan antarmuka antara mode gelap (dark mode) yang elegan dan mode terang (light mode).

Riwayat Catatan Latihan Harian: Log catatan ringkasan aktivitas latihan harian yang tersusun rapi di bagian bawah aplikasi beserta waktu dan tanggal penyelesaiannya.
